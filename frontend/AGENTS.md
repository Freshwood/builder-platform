# Frontend – guide for AI coding agents

Vite + React 19 single-page app (ADR-0009). It replaces the Next.js client in `apps/web`.

## Stack

- Vite with `@vitejs/plugin-react` and `@tailwindcss/vite` (Tailwind 4, tokens in `src/index.css`).
- React Router v7 (`createBrowserRouter`, routes in `src/router.tsx`, pages in `src/routes`).
- `@ai-sdk/react` `useChat` against `POST /api/chat` (AI SDK UI message stream), TanStack Query,
  raw three.js (`Viewer3D`, loaded with `React.lazy`).
- API client generated by `@hey-api/openapi-ts` into `src/api/gen` from `../backend/openapi.json`
  (fallback: `../packages/api-client/openapi.json`). Import it via `@/api`. Never edit `src/api/gen`
  by hand; run `pnpm generate` and commit the output.
- In development the Vite proxy forwards `/api` to `API_ORIGIN` (default `http://localhost:8000`,
  300 s timeout, unbuffered for SSE). In production the Go binary serves `dist/`.

## Commands (`corepack pnpm --filter @homeworking/frontend <script>`)

- `dev` (pass `--port`), `build` (`tsc -b && vite build`), `preview`
- `lint` (ESLint flat config: typescript-eslint, react-hooks, react-refresh), `typecheck`, `format`
- `generate`: regenerate the API client after backend API changes.
- Functional scenarios: `tests/features/frontend/*.feature` (see `tests/README.md`).

## Conventions

- `data-testid` attributes, ARIA labels/roles and visible texts are a contract with the BDD
  scenarios in `tests/features/frontend` and their steps in `tests/steps/ui.steps.ts`. Change them
  only together with the scenarios.
- User-facing texts are German, code comments are English.
- Page titles are set per route with `useDocumentTitle` (`src/lib/title.ts`).
- Component files export only components (React Fast Refresh); shared constants and helpers go
  to `src/lib`.
- The UI never calculates construction figures; it shows what the API returns.
